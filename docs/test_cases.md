## 测试设计方法对应

- 等价类：合法/未知物品，购买阶段/非购买阶段，合法/非法状态。
- 边界值：余额等于价格、比价格少 1；余额上限；上下文半径 0。
- 状态迁移：对局主流程和局内 BUY/COMBAT/ROUND_END。
- 错误推测：重复网络包、延迟事件、客户端旧快照覆盖、半成功事务。
- 场景法：从匹配到赛后结算的玩家完整链路。
